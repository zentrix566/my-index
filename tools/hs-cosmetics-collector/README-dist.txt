炉石收藏与成就采集器 · 使用说明
================================

作用：趁《炉石传说》运行期间，读取你「已拥有」的 卡背 / 幸运币 / 英雄皮肤 / 成就，
      生成 2 个 JSON 文件，在网站导入即可同步你的收藏与成就进度。

【使用前】
1. 电脑系统是 Windows（需要 .NET Framework 4.8，Windows 10/11 一般已自带；
   若双击报错「找不到 .NET Framework」，去微软官网装一个 4.8 即可）。
2. 先打开《炉石传说》，并进入任意界面（主菜单即可）。
   建议同时开着 Firestone / Overwolf（本工具依赖其内存读取库，已随包附带在 lib/ 里）。

【运行】
3. 保持本文件夹结构：HsCosmeticsCollector.exe 与 lib/ 文件夹在同一级，不要拆开。
4. 双击 HsCosmeticsCollector.exe，会打开图形界面窗口：
   - 顶部会实时显示「炉石传说：运行中」与「读取库：已就绪」两个绿色状态；
   - 状态都变绿后，点「开始采集」按钮；
   - 窗口中间会滚动显示采集日志；结束后底部出现绿色摘要（各类数量 + 输出目录）；
   - 点「打开输出文件夹」可直接定位到导出的文件；
   - 点「打开网站导入页」会打开网站的炉石收藏页（登录后即可导入）；
   - 有问题点「复制日志」反馈。
   （自部署/本地环境的用户：在 exe 旁新建 site-url.txt，写一行自己的导入页地址
     如 http://localhost:5173/hearthstone/collection，按钮就会打开它。）
5. 若仍想用命令行（排障时），在 PowerShell 里运行：
       .\HsCosmeticsCollector.exe diag
   输出会写入 stdout（可重定向到文件）。

【产物】
运行后，输出文件夹（界面上会显示路径，一般在本文件夹下）会多出 2 个文件：
   cosmetics.json      外观收藏（卡背/幸运币/英雄皮肤已拥有的 ID 列表，合并在一个文件里）
   achievements.json   成就（totalCompleted 官方总完成数 / categories 分类完成度 /
                        items 逐条明细：每个成就的 id / status / statusText / progress / isComplete）
导入位置（需登录网站）：
   - 「炉石收藏」页面 → 选择采集的 JSON 文件 → 导入 cosmetics.json
   - 「炉石成就」页面 → 导出与备份 → 导入游戏内进度 → 选择 achievements.json
   成就导入只会推进进度，不会清除你已手动勾选的内容。

【关于杀毒软件 / Windows SmartScreen 误报】
本程序的工作原理是读取炉石传说的游戏内存（与 Firestone 插件同源的技术），
没有数字签名证书的绿色小工具都可能被杀软启发式误判。如遇提示：
1. Microsoft Defender：弹窗选「更多信息 → 仍要运行」；
   或「设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
   排除项」把本文件夹加入排除。
2. 其他杀软：在弹窗里选择「信任 / 加入白名单」。
3. 建议下载后核对发布页公布的 SHA256，确认文件未被篡改。
4. 若确认是误报，可在微软安全智能申诉页提交样本：
   https://www.microsoft.com/wdsi/filesubmission
   （开发者提交后，Defender 误报通常 1~3 个工作日内解除。）

【常见问题】
Q: 界面显示「读取库：缺失」？
A: 确认 lib/ 文件夹与 exe 在同一目录，且里面的 UnitySpy 两个 DLL 没被杀软删掉
   （被删的话先加白名单，再解压一份新的）。

Q: 报错「炉石未运行 / 无法附加到进程」？
A: 先启动炉石传说并进入游戏，等界面顶部状态变绿后再点「开始采集」。

Q: 数字和我游戏里看到的不一致？
A: 本工具读的是「已拥有」集合。游戏收藏界面显示的「总数」可能略多（含默认/未解锁项），
   且本工具不读「总数」接口，只报已拥有数。个别新内容若目录未更新，名称可能暂时缺失。

Q: 成就导入后有些成就没变化？
A: 网站成就库收录的是扩展包成就；游戏内「生涯 / 游戏玩法 / 冒险模式」等其他类别
   以及个别未收录成就会被跳过（导入预览里会显示跳过数量）。
