Firestone 收藏导出工具

使用方法：
1. 打开 Firestone，进入一次它的收藏页面；
2. 双击“导出Firestone收藏.cmd”；
3. 桌面会生成“Firestone收藏导出.json”；
4. 登录网站，在外观收藏页点击“选择 Firestone 导出文件”，选择该 JSON，先预览数量，再确认导入。

说明：
- 工具只读取 Firestone 的本地缓存，不会修改 Firestone、炉石客户端或网站数据。
- 卡背和幸运币会在缓存存在时导出。Firestone 当前缓存的战棋英雄皮肤不等同于构筑英雄皮肤，网站会提示但暂不导入。
- 本工具需要 Windows 已安装 Node.js。后续可将此目录打包成独立 EXE，届时无需 Node.js。
